    HACS 操作指引

    HACS 是 Home Assistant 常用的扩展安装工具。

    在新标签页打开 HACS ↗

    先保留现在的状态

    请不要反复安装，也不要删除现有设备。保存下方诊断信息，和维护者一起确认恢复方法。

    不需要发送密码或家庭网络资料。

    打开 Home Assistant ↗

    设置 → 设备与服务 → 添加集成 → NexHome。中控查找和确认都在 Home Assistant 中完成。安装助手可以停止。

    请先保存诊断信息，和维护者确认安装来源。本页不会直接覆盖。
