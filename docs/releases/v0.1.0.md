# NexHome 滨融府友邻加强版 0.1.0

首个公开版本，基于 NexHome 官方 Home Assistant 组件 v1.1.16 改进。

- 为请求设置明确超时，避免中控异常时长期占住 HA 请求。
- 典型单中控家庭网络支持自动发现。
- 更合理地展示灯光、空调、窗帘等设备；已有安装优先保留名称、房间、隐藏和自动化引用。
- 控制后读取真实状态，确认不足时不伪造成功。
- Home Assistant OS 安装助手，以及 NAS / Docker / Container / Linux 的一条命令交互式入口。
- 本地优先，不默认上传家庭设备状态。

主要基于**滨融府大平层原配 NexHome 系统**实测。其他户型和设备组合可能可用，但不属于完整已验证范围。当前主要实测平台为 amd64 HAOS 与 Linux Docker；无位置窗帘不会伪造位置，原配语音中控仍未验收。

[开始安装：安装与使用指南](https://github.com/Doggiekong/nexhome-neighbor-edition/blob/main/docs/%E5%AE%89%E8%A3%85%E4%B8%8E%E4%BD%BF%E7%94%A8%E6%8C%87%E5%8D%97.md)

App 与 Terminal 二选一。建议先保留 HA 备份；来源或恢复状态不明确时会停止。此次是 GitHub 公开发布，**不等于 HACS 上架**。
