# 隐私与安全

友邻加强版帮助你把自己家的 NexHome 设备接入自己的 Home Assistant。家庭设备仍由自己的 Home Assistant 账号、权限和网络管理。

## 设备信息在哪里处理

中控查找、设备状态和控制主要在家庭网络中完成。不默认上传设备状态、家庭成员、在家情况、家庭位置、自动化历史或使用记录，不默认开启统计或日志回传。

下载安装文件会连接 GitHub，服务方可能看到请求 IP 等普通访问记录；下载不会附带中控识别信息或家庭设备状态。

## 不需要把密码交给维护者

Terminal 安装时会登录一次自己的 Home Assistant，账号和密码只用于本地安装过程，不上传到项目。不要通过聊天、Issue 或邮件发送密码、访问令牌、Wi-Fi 密码或完整中控识别信息。

安装助手需要相应管理权限，用于安装或更新 NexHome、备份文件及必要时重启 Home Assistant。开始前会显示提示，由你确认。

## 保留原有设置

正常升级优先保留设备名称、隐藏状态、房间和自动化引用；不能确认安全时会停止。不要通过删除原有 NexHome 配置来解决安装问题。

不自动修改仪表盘、自动化、家庭成员或网络设置，也不为维护者或邻居建立远程账号、隧道或其他远程访问。你自己原有的远程访问继续由你管理。

## 备份与恢复

安装前建议保留 Home Assistant 备份。安装助手也会备份要替换的 NexHome 文件；这些文件备份不等于整台 Home Assistant 的完整备份。

安装失败时会尝试恢复旧文件。断电、权限或连接问题可能使自动恢复无法完成，此时会停止并提示恢复方法。重新放回旧文件不一定能撤销全部设置变化，请保留备份并按提示处理，不要反复安装。

## 分享诊断信息

技术详情可复制或导出经过脱敏的诊断信息，供排查问题使用；不会默认上传。分享前仍应检查内容，截图要遮住家庭成员、精确位置和其他私人信息。

完整备份可能含有敏感配置，应保存在自己控制的位置，不要当作诊断附件发给别人。
